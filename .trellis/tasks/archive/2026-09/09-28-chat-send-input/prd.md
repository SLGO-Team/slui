# SLUI 聊天输入（发送 + 结果提示）

## Goal

在覆盖层里提供 CS2 式聊天输入：Y 全体、U 团队，回车发送 `command.chat.send`，并显示 `command.result`。
父任务 `08-25-chat` 的消息历史、实时接收、去重不在本任务范围（插件尚未推送 `chat.message`）。

## 已知事实（调研结论）

- `src/features/chat/model.ts` 已有 `createChatCommand` / `validateChatBody`，无调用方；`MAX_CHAT_LENGTH = 240`。
- Rust 低级键盘钩子对 Y 发 `slgo-shortcut "chat"`，**不吞键**：按键同时送达游戏；覆盖层获得焦点后，在输入框里打字仍会触发全局快捷键。
- 商店的 `overlayInteractive` 只接管鼠标，**不激活窗口**；聊天要打字，必须把覆盖层设为前台，关闭时把前台还给游戏。
- 插件 `ChatManager`：长度上限 120（按文本元素计），1 秒共享冷却；scope 只接受 team/global。
- 插件 SSSS“文字消息区”显隐切换默认也是 Y；插件未占用 U。
- `command.result.reason` 可能是插件中文提示，也可能是机器码：插件 `invalid-command` / `player-not-in-game` / `internal-error`；sidecar `rate-limited` / `timeout` / `plugin-unavailable`。
- Mock 连接的 `send()` 不回 `command.result`。

## Requirements

### 打开
- Y 打开输入框、范围为全体；U 打开输入框、范围为团队。
- 只有同时满足以下条件才打开：覆盖层已启用、游戏窗口在前台、SLGO 会话为 `live`。否则按键无效果。浏览器预览不检查前台。
- 打开聊天会关闭商店（同一时间只有一个接管输入的 UI）。
- 打开时覆盖层接管鼠标和键盘（覆盖层成为前台窗口），输入框自动获得焦点。

### 输入
- Tab 在全体/团队间切换（CS2 没有此功能，作为隐藏快捷键保留；界面上不显示范围按钮）。只提供这两个范围。
- 输入框打开期间，Y/U/商店热键等全局快捷键不再触发任何 UI（它们是正常字符输入）。
- 支持中文输入法：输入法组字过程中按回车/Esc 不触发发送/关闭。
- 长度上限 120（与插件一致，按字符而非 UTF-16 计）；与 CS2 `maxchars` 一样，达到上限后无法继续输入，不显示计数。
- 按住 Y/U 打开时，自动重复的按键不会写进输入框。

### 发送与关闭
- 回车：空白消息不发送（保持打开）；有效消息生成 `command.chat.send`，立即关闭输入框、清空草稿，焦点还给游戏。
- Esc：关闭并丢弃草稿。
- 覆盖层失焦（切窗口、点到别处）、会话离开 `live`、覆盖层被停用：关闭并**保留**草稿。
- 被拒绝或失败：保留该条消息为草稿及其范围，下次按 Y/U 打开时自动填回（范围以按键为准）。

### 结果显示（写进历史区，与 CS2 同构）
- 不再有独立提示条。发送成功：自己的消息作为一行进入历史区（本地回显，接入 `chat.message` 后由服务端消息取代）；失败：一行系统消息“发送失败：原因”。
- 插件中文 reason 原样显示；已知机器码映射为中文，未知码显示通用文案。
- 发送中会话断开：失败“连接已断开”；10 秒无结果：失败“服务器未响应”。
- 历史区保留最近 50 行。关闭聊天后，最近的行在原位置短暂显示后淡出（具体时长与样式以截图为准）。

### 视觉（按 CS2 `hudchat.xml` / `hudchat.css` 还原）
- 结构与尺寸完全按源码：`ChatContainer`（左 10px、离底 72px）→ `ChatMain`（0.75 黑底）→ `ChatFG`（553px、8px 外边距）→ `ChatHistory`（327px，0.75 黑底 + `#00000099` 文本底，18px 粗体，底部对齐）+ `ChatTextEntry`（48px，上距 8px，0.75 黑底）→ `ChatTextEntryBox`（450×36，左距 15px，20px Stratum2 Light，白字，darkgrey 占位符）+ `ChatSendButton`（75px，22px Stratum2 大写，灰 / 可用时 `#A0A0A0` 粗体 / 悬停白，0.2s 颜色过渡）。
- 范围只体现在占位符文案里（全体 / 团队不同文案）。
- 整个面板随覆盖层等比缩放，锚定屏幕左下角。
- 游戏内截图是最终标准（用户提供 1920×1080 中文客户端截图：Y 打开、U 打开、有输入、有历史、关闭后残留）。源码缺失的内容先按源码+暂定值实现，并集中在一处常量里，收到截图后逐项对齐：占位符与按钮文案、历史行格式与颜色、中文字体回退、关闭后残留与淡出。

## Out of Scope / 后续任务

- **插件检测 SLUI 并禁用重复功能**（跨 slgo-backend IPC + SLGO 插件，已建任务 `SLGO/.trellis/tasks/09-28-slui-presence`）：插件需要知道玩家当前使用 SLUI 聊天输入，此时忽略自身 Y 的“文字消息区”切换。需要新增 sidecar→插件 的在场/能力消息。在场应表示“覆盖层已启用且会话 live”，而不只是“会话 live”，因为覆盖层停用时 SLUI 不会响应 Y。在它完成前，Y 同时切换插件消息区属于已知问题。
- `chat.message` 接收、去重、跨实例隔离（等插件推送；本任务的历史区只承载本地回显和系统行）。
