# 小地图 CS2 对齐：观战选中框与队友编号

父任务：`11-17-minimap-cs2-parity`（D15、D16）。`11-17-minimap-cs2-slui` 已合入（#116）后开始；与
`11-17-minimap-speaking` 改同一处标记代码，两者依次进行、依次开 PR。

## Goal

- D15：复刻 CS2 雷达的观战选中框 `#Selected`，框住观察者正在跟随的玩家。
- D16：复刻 CS2 画在玩家点上的编号 `#PlayerNumber`，只给无队伍观察者看。

## CS2 依据（逆向结论，详见 `archive/2026-11/11-17-minimap-cs2-slui/research/cs2-radar-client-re.md`）

- 选中框：本地玩家是观察者时，框住其第一/第三人称跟随的那名存活玩家；自由视角不框任何人；活着的玩家没有。
  只在存活、在图内的点上画（死亡 X、问号、边缘箭头都没有）。图形是白色水滴圈加向前的光晕，42×36，y −10，
  随朝向旋转，不染色。
- 编号：只给观察者队伍 / GOTV / 看 demo 的人显示，比赛中的玩家（活着或死后）都看不到。编号按队伍计数器的顺序
  连续排：CT 一方在前、T 一方在后，第 i 个（从 0 开始）显示 `(i + 1) % 10`，第 11 人起没有编号。
  10px Stratum2 medium，黑色，居中，不旋转。同样只在存活、在图内的点上画。
- 本地录像都是以队员身份打的人机局：没有任何编号（与条件一致），也没有跟随队友的片段，不能直接佐证选中框。

## Requirements（用户 11-17 决定）

- R1 选中框按 CS2：viewer 不是存活玩家（死后跟随队友、无队伍观察者跟随某人、回放跟随某名玩家）时，框住
  正在跟随的存活玩家；回放自由视角、活着的玩家都不显示。
- R2 编号保留，只给无队伍观察者（demo 回放观察者、无队伍旁观）显示。
- R3 编号规则按 CS2 实际行为：SCP 一方（SLGO 的 CT 侧）在前、NTF 一方（T 侧）在后，各自按 `match.snapshot`
  的队员顺序（与槽位颜色同源）连续编号 1–9、0；第 11 人起不显示。不加协议字段。
- R4 不做脚步声圈、`PlayerLetter`（色盲字母）和顶部 HUD 头像上的编号。

## Acceptance

- [ ] 死后跟随队友时，被跟随的队友点上有白色选中框，随其朝向旋转；活着时自己没有选中框。
- [ ] 回放跟随某玩家时有选中框；回放自由视角没有。死亡 X、问号和边缘箭头上没有选中框。
- [ ] 无队伍观察者看到每个存活、在图内的点上有黑色编号（SCP 在前、NTF 在后，1–9、0，第 11 人起无）；
      有队伍的 viewer（活着或死后）看不到编号。
- [ ] 尺寸、颜色、位置与 CS2 一致，随 `--radar-icon-scale` 一起缩放；编号不旋转。
- [ ] model 测试覆盖选中与编号的条件和编号规则；minimap 视觉审计断言选中框与编号的出现和样式。
- [ ] `.trellis/spec/frontend/minimap.md` 已更新。
