# @slgo/protocol

The SLGO protocol v0 wire contract shared by SLUI and the SLGO backend: TypeScript types, parsers and validators
(`src/`) and the JSON Schemas and examples (`v0/`). The protocol itself, its topology, envelope, events and
commands, is described in [`v0/README.md`](v0/README.md).
